# VoiceLite v0.1 design

用户已确认：独立开源 Windows 桌面产品；简化日常声音克隆操作；服务完全没有安装 GPT-SoVITS 的普通用户；首版提供完整离线包。2026-11-02 用户指示“开干吧”，授权实施以下方案，继续遵守原开发计划的模型、隐私与上游保护约束。

## Intent and scope

WPF / .NET 8 / MVVM 客户端复用现有 GPT-SoVITS `api_v2.py`。用户选择参考录音、填写对应文字、选择语言、输入合成文字，生成、取消、试听并保存 WAV。记住上次的设置。界面明确区分真实引擎与模拟演示。

原 M2 中的环境检测和离线打包提前到首版；下载器、训练、云账号、多平台、多音色库仍在后续。当前目录开发客户端，已有整合包保持独立，不能覆盖其 Python 环境或推理代码。

## Approaches

讨论过首次启动联网下载资源与完整离线分发。用户选择完整离线分发，接受资源随包产生的体积。实现先采用 Windows x64 目录式解压包（实现者选择，便于验证和迁移），包含自带 .NET 运行时的客户端、引擎、便携 Python / Torch、FFmpeg、一套固定模型、文本处理资源、许可和校验清单。源仓库仅含代码、脚本、文档和清单，发行资源不进入 Git。

## Components and boundaries

- Core：配置、请求、环境报告、服务接口、WAV 验证与 UI 无关的状态。
- Infrastructure：EnvironmentProbe、EngineProcessManager、TtsApiClient、AudioImportService、配置和日志。
- Desktop：WPF 窗口与 ViewModel，异步命令，录音与结果试听、保存对话框。
- Engine：启动配置保存在 VoiceLite 数据目录；只绑定 127.0.0.1。只访问本应用启动的、端口归属与进程树均已核实的服务。无专门 `/health` 时使用实际 OpenAPI 契约与启动结果检测，不能声称模型输出已验证。

启动、HTTP、FFmpeg 均有超时和取消。取消推理关闭并回收自己的引擎进程树，再次生成重新启动；仅取消 HTTP 不能当作停止 GPU 推理。关闭窗口回收应用托管进程。端口已被占用时拒绝通信。未知服务不会被请求或终止。

录音复制/转换到受控目录，绝对路径传给 `/tts`，不覆盖输入。非流式 WAV 输出先验证再落盘；错误不能保存成 WAV。日志不记录全文和完整请求。用户文件、运行时与权重不纳入源码。

## Offline and verification

首版支持范围从 Windows 11 x64 + NVIDIA（本机 RTX 4070 Laptop 8GB）验证开始；驱动属于前置条件，CPU 可用性不预先承诺。包不得依赖开发机绝对路径、用户缓存、Conda、已装 Python/.NET；辅助词典、tokenizer、NLTK 等随所选模型路径核查。发布前需要无缓存、无网络的干净 Windows 真机验收及逐项再分发许可核查。

自动化覆盖端口冲突、就绪识别、异常退出、超时/取消、路径含中文空格、请求 JSON、错误响应、非法 WAV、音频转换和设置持久化。真实例子使用 Windows SAPI 生成的测试参考音频，不打包用户音频；记录模型、耗时、WAV 规格和播放证据。缺失资源/许可/干净机器不得标为已通过。
