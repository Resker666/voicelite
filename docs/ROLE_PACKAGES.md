# 声音角色包（0.1.4）

角色包把训练好的两组推理权重、默认参考录音和参考文字放在一起。使用时仍需完整 VoiceLite 离线包提供运行时和基础资源。

## 日常使用

1. 打开 VoiceLite，点击“声音角色”旁的“导入角色包”。
2. 选择来源可信、与本版引擎兼容的 ZIP，等待校验和导入完成。
3. 导入后自动选中角色，参考录音、文字和语言已填好。输入希望合成的文字，点击“生成语音”。
4. 生成完成后试听或保存 WAV。角色自带主/辅助参考也可试听，默认参考输入保持只读。
5. 从角色下拉框选择“自定义参考声音”，恢复导入前的自定义参考输入。切换角色保留合成文字，清除上一角色的结果选择。

导入与生成过程中可取消；窗口关闭会等待任务收尾。切换角色后的首次生成需要重新加载两组模型，耗时接近冷启动。同一角色继续生成复用引擎。

角色复制到 `%LOCALAPPDATA%\VoiceLite\roles\<随机ID>`，重启恢复上次选择。原 ZIP 不作为运行时引用，建议另行保存用于迁移。换电脑仅克隆 Git 仓库不会带上私人角色或音频；需要兼容的完整离线包与角色 ZIP。源码和客户端更新均不包含私人角色模型。

模型加载使用上游能力，仅导入来源可信的角色包。文件 SHA 校验用于发现缺损/改动，不是作者签名或可信来源认证。

## 当前兼容格式

首版只接受本项目实验导出的 `voicelite-role-experiment-0`，引擎家族 `GPT-SoVITS`、型号 `v2ProPlus`，并匹配已审计 API SHA。支持中文和英文参考；其它 GPT-SoVITS 型号或任意上游权重 ZIP 不能直接当作此格式导入。

ZIP 根目录应直接包含 `character.json`；另有两组权重（`.ckpt` GPT 与 `.pth` SoVITS）、一条主参考、0–3 条辅助录音和可选 `README.txt`。音频只支持 WAV/MP3/OGG，仍需满足原参考录音时长要求。全部 payload 必须列入 `files`，每项包含唯一相对路径、字节数和 SHA256；未知附加文件会被拒绝。不允许额外的外层目录、目录条目、链接或 Windows 路径别名。

清单的必填字段为 `schema`、`name`、`version`、`engine_family`、`model_version`、`api_sha256`、`gpt`、`sovits`、`reference`、`prompt_text`、`language`、`auxiliary`、`files`。`auxiliary` 没有内容时填写空数组；文件路径使用 `/` 分隔，不可为绝对路径或包含 `..`。其他实验记录字段可以保留。

压缩包与累计解压体积均最多 1 GiB；每个权重最多 512 MiB，每条参考最多 64 MiB，清单/说明最多 64 KiB。导入使用本次独有的临时目录，校验完成后才进入角色列表，失败/取消清理本次临时文件，不覆盖已有角色。

生成前再次校验已安装角色的文件大小、SHA 和路径。损坏角色不能启动推理，其他角色和自定义输入仍可使用。请通过重新导入恢复损坏角色，避免直接修改角色库内部清单或权重。

## 本机 E 候选

用户在 D/E/F 试听后选择 E 更像。E 使用原 GPT 底模与微调 9 轮的 SoVITS，包为本机忽略目录中的 `dist/VoiceLite-hutao-E-experimental-20261104.zip`，不是源码仓库中的公共下载。

0.1.4 已用该包完成真实 GPU GUI 生成、播放、导出和重启恢复。完整训练状态与推理包不同：此包不含优化器、完整训练素材或运行时，续训仍需保存实验中的完整检查点与数据。见 [训练记录](CHARACTER_TRAINING.md) 和 [测试报告](TEST_REPORT.md)。
