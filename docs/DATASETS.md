# 素材管理与文字校对（0.1.5）

点击主窗口的“训练素材”，为同一个声音新建素材集。素材窗口与合成窗口分开操作；0.1.6进入素材窗口时先释放本应用推理引擎，避免与训练争抢显存。

## 日常步骤

1. 输入素材集名称，点击“新建素材集”；已有素材从上方下拉框选择。
2. 点击“批量导入录音”，选择2–18秒的WAV/MP3/OGG短句。同一文件内容会去重，无法读取、超长或过短的片段会列出原因，原录音不改。
3. 选择一行并试听。在右侧填写录音实际说出的文字，选择中文或英文；不要填写背景人声或没有说出的内容。
4. 听完并逐字检查后，勾选“已听音并逐字校对”。不合适的片段取消“纳入训练”。修改文字或语言会撤销校对标记。
5. 点击“保存校对”。切换素材集、导入、转写、导出和正常关闭窗口前也会保存修改。保存冲突会提示重新载入；“重新载入”会询问是否丢弃尚未保存的修改。
6. 点击“导出训练集”，在所选父目录内创建新目录，只复制已启用且已校对的音频、相对路径清单和 `train.list`，不覆盖已有导出。

列表保留源文件名、时长和待填写/待校对/已校对/已排除状态。每个素材集最多500条，每份源文件最多200 MB。较长录音需先裁成独立短句；本版不会悄悄截短导入。

## 离线中文转写

展开“离线转写资源”，选择已经包含本地模型和运行时的完整GPT-SoVITS整合包。自动转写用CPU，不会下载模型、安装包或改动现有Python环境。首次加载需要等待，可取消；取消或关闭会回收本应用启动的转写进程和临时任务。

“自动转写空白项”只处理启用、未校对且文字为空的条目；手动修改过的文字与已有草稿不会覆盖。中文识别结果始终是待校对草稿，不能自动当作人工确认。英文素材可手动填写英文并选择英文语言。

当前日常推理包有相应Python依赖，但**没有离线转写模型**。原整合包中的下列目录应各含 `model.pt`、`config.yaml` 及配套词表/配置：

- `tools/asr/models/speech_paraformer-large_asr_nat-zh-cn-16k-common-vocab8404-pytorch`
- `tools/asr/models/speech_fsmn_vad_zh-cn-16k-common-pytorch`
- `tools/asr/models/punc_ct-transformer_zh-cn-common-vocab272727-pytorch`

资源缺失时窗口会明确提示选择兼容完整整合包。已有本机资源可直接复用，无须把几个GB模型放进客户端更新。仓库和客户端更新不携带这些模型；本机测试不代表新的完整离线发行包已经重新制作。

## 保存、导出与迁移

默认素材库为 `%LOCALAPPDATA%\VoiceLite\datasets\<素材集ID>`，内含 `dataset.json` 与 `wavs`。导入副本统一为32kHz、单声道、16位PCM WAV；元数据记录源内容与副本SHA。试听、转写和导出前核验副本，损坏文件给出提示；一份坏清单不会阻止其它素材集打开。

正常关闭素材窗口后，迁移尚未校对完的项目时复制对应的**整个素材集子目录**到另一台电脑同名素材库，保留目录ID；未完成内容不应依靠“导出训练集”迁移，因为训练导出只含已校对的条目。保留原录音，源录音不会随Git迁移。素材窗口记住的资源路径保存在单独的 `dataset-ui.json`，换机器后可重新选择。

训练导出目录包括：

```text
VoiceLite-dataset-…/
  dataset.json
  train.list
  wavs/<片段ID>.wav
```

清单内不带开发机绝对路径，校对标记来自用户自己的操作，不是独立质量认证。训练CLI再次校验所有标签、音频与SHA；无校对内容时拒绝导出。0.1.6可直接点击“训练新版本”完成独立8轮任务与角色ZIP导出，资源、取消、恢复边界见 [训练说明](TRAINING_CLI.md)。
